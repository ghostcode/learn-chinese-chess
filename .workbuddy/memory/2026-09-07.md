# 2026-09-07 · learn-chinese-chess 立项

## 目标

从零搭建中国象棋学习网站「弈境」：Vite 8 + React 19 + TS 6 + Tailwind v4 + React Router 7，古典宣纸/水墨/朱印风格。

## 完成项

1. 脚手架：脚手架由 `npm create vite@latest` 生成（已 8.x），覆盖 vite.config 加入 `@tailwindcss/vite`，把 `src/index.css` 改为 Tailwind v4 + 自定义 `@theme` 古典主题
2. 引擎（`src/engine/`）：纯 TS，零外部依赖
   - `types.ts`：棋子/坐标/九宫/河界常量
   - `board.ts`：FEN 解析、伪合法走法、合法走法（过滤自杀）、isAttacked（含将帅照面飞将）
   - `notation.ts`：中文记谱双向解析，支持「前/中/后」与多子序号
   - `useGame.ts`：预置谱 + 手动走子 + 自动播放 + 悔棋
3. 棋盘（`ChessBoard.tsx`）：SVG 渲染，木色底 + 楚河汉界 + 炮/兵位 L 形标记 + 选中/可走点/上一步/将军红圈
4. 棋盘+控制条（`GameBoard.tsx`）：棋盘 + 棋谱列表 + 前进/后退/自动播放/速度/翻转/复位
5. 数据（`src/data/`）：10 套开局、12 种杀法、4 章入门/4 章中级/4 章高级课程
6. 页面（`src/pages/`）：首页、入门/中级/高级、开局/杀法（列表+详情）、打谱、记谱法
7. 校验脚本（`scripts/verify.mjs`）：用 vite ssrLoadModule 加载 TS，自动校验 119 着棋谱

## 校验结果

- 10 套开局全部通过（12 着 × 10）
- 12 种杀法通过：6 个绝杀已验证（马后炮、铁门栓、钓鱼马、重炮、卧槽马、大刀剜心、二鬼拍门 = 6 个 mate ✓）
- 修复了初始数据中的 9 处问题：FEN 列数错误 3 个、将帅照面 2 个、着法被阻挡/无法解析 4 个

## 关键技术细节

- Tailwind v4：使用 `@import "tailwindcss";` 与 `@theme { --color-... }` 定义主题；不再需要 tailwind.config.js
- 记谱法纵线换算：红 file = 9 - col；黑 file = col + 1
- 棋谱校验用 vite 的 ssrLoadModule 加载 TS，无需额外依赖

## 构建结果

`npm run build` → 41 模块、314KB JS（103KB gzip），构建时间 ~720ms
